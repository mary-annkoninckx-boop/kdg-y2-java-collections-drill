## 📚 Exercises Overview

---

### 📍 Exercise 1: Filtering and Sorting Postal Codes (`Set`)

**Goal:** Choosing the right `Collection` for uniqueness and automatic sorting.

**Case:**  
You receive an unsorted list of postal codes containing duplicates:  
`[2000, 9000, 1000, 2000, 3000, 1000, 9000]`

**Questions:**
1. Which interface/class do you use to automatically filter out all duplicate postal codes?
2. Which specific class (`HashSet`, `TreeSet`, or `LinkedHashSet`) do you choose if the postal codes also need to be **automatically sorted** in ascending order?

<details>
<summary>💡 Solution & Answer</summary>

1. **`Set`** automatically removes duplicate entries.
2. **`TreeSet`** additionally ensures that elements are stored immediately in their natural ordering (ascending).
</details>

---

### 👨‍💼 Exercise 2: External Employee Sorting (`Comparator`)

**Goal:** Sorting objects whose original class structure you cannot or should not modify.

**Case:**  
Given an `Employee` class with `name` and `salary` properties. You want to sort a `List<Employee>` by salary from **low to high**, but the `Employee` class cannot implement `Comparable`.

**Questions:**
1. Which interface do you use to create an external sorter: `Comparable` or `Comparator`?
2. What should the `compare(Employee e1, Employee e2)` method return if `e1` earns less than `e2` when sorting from low to high?

<details>
<summary>💡 Solution & Answer</summary>

1. **`Comparator<Employee>`** (e.g., via a Lambda expression or a separate dedicated class).
2. A **negative integer** (such as `-1` or `Double.compare(e1.getSalary(), e2.getSalary())`), because `e1` should be placed **before** `e2` in the sorted list.
</details>

### 🔤 Exercise 3: Word Counter (`Map`)

**Goal:** Working with Key-Value pairs and tracking element frequencies.

**Case:**  
You process a sequence of words: `"apple"`, `"banana"`, `"apple"`, `"lemon"`, `"banana"`, `"apple"`. You want to track the frequency of each word.

**Questions:**
1. Which `Map<K, V>` data structure do you pick, and what are the key (`K`) and value (`V`) types?
2. How do you process a word depending on whether it already exists in the Map or not?

<details>
<summary>💡 Solution & Answer</summary>

1. **`Map<String, Integer>`** (for example, a `HashMap<String, Integer>`).
2. **Logic:**
    * If the key does **not** exist yet: insert it with a value of `1`.
    * If the key **does** exist: retrieve the current value, increment it by `1`, and update the key entry.
</details>
